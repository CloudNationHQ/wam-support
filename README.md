## Raising Issues

Issues, feature requests, and bugs for a **specific module** should be raised in that module's repository directly.

For **general WAM framework questions**, use the GitHub Issues in this repository.

For more details on the support process, see [wam.cloudnation.nl/support](https://wam.cloudnation.nl/support).

## Contributing

Before proposing or creating a new module, read the [contributing guidelines](https://wam.cloudnation.nl/contributing). Every new module requires a Module Proposal issue approved by the WAM core team.
